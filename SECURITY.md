# Security Policy

The **Bienvenue à La Suite** team takes the security and privacy of French public administration data very seriously. We appreciate the responsible disclosure of any potential security vulnerabilities.

---

## Supported Versions

Only the latest release and the current `main` branch receive security patches.

| Version | Supported          |
| :------ | :----------------- |
| `main`  | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

**Please do NOT report security vulnerabilities through public GitHub Issues, discussions, or pull requests.**

Instead, please report vulnerabilities privately:

1. **Email**: Contact the security team at `contact@lasuite.numerique.gouv.fr` or reach out to the project maintainers directly.
2. **Subject**: `[SECURITY] Vulnerability report in Bienvenue à La Suite`
3. **Include the following information**:
   - Description of the vulnerability and attack vector.
   - Exact steps or proof-of-concept (PoC) to reproduce the issue.
   - Affected component (Backend API, OIDC authentication, Grist sync, or Frontend UI).
   - Potential impact and any suggested mitigations.

### Response Timeline

- **Initial Acknowledgement**: Within 48 business hours.
- **Triage & Assessment**: Within 5 business days.
- **Fix & Disclosure**: Coordinated disclosure after a patch is validated and deployed.
